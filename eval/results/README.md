# Kết quả các lần chạy

Mỗi lần chạy `run_golden_set.py`/`run_stateful_scenarios.py` sinh ra file
MỚI (đặt tên theo ngày, không ghi đè) — xem `eval/README.md` cho lệnh chạy.
File này chỉ là mục lục, cập nhật thủ công sau mỗi lần chạy có ý nghĩa để
biết lần chạy nào là mốc so sánh.
